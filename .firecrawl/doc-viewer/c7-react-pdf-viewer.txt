### Core Viewer and Default Layout Plugin Setup in React

Source: https://github.com/react-pdf-viewer/react-pdf-viewer/blob/master/README.md

Demonstrates how to set up the core React PDF Viewer component and the default layout plugin. It includes necessary imports for the viewer and plugin, styling, plugin instantiation, and the basic structure for embedding the viewer with a file URL and plugins.

```javascript
// Core viewer
import { Viewer } from '@react-pdf-viewer/core';

// Plugins
import { defaultLayoutPlugin } from '@react-pdf-viewer/default-layout';

// Import styles
import '@react-pdf-viewer/core/lib/styles/index.css';
import '@react-pdf-viewer/default-layout/lib/styles/index.css';

// Create new plugin instance
const defaultLayoutPluginInstance = defaultLayoutPlugin();

<Viewer
    fileUrl='/assets/pdf-open-parameters.pdf'
    plugins={[
        // Register plugins
        defaultLayoutPluginInstance,
        ...
    ]}
/>
```

### Upgrade Viewer and Plugin Usage (JavaScript)

Source: https://github.com/react-pdf-viewer/react-pdf-viewer/blob/master/changelogs/v2.0.1.md

Shows the code changes required to upgrade from the old Viewer component to the new one in v2.0.1, including importing the new Viewer, default layout plugin, and their respective styles.

```javascript
// Old Viewer
import Viewer from '@phuocng/react-pdf-viewer';

// New Viewer
import { Viewer } from '@react-pdf-viewer/core';

// Plugins
import { defaultLayoutPlugin } from '@react-pdf-viewer/default-layout';

// Import styles
import '@react-pdf-viewer/core/lib/styles/index.css';
import '@react-pdf-viewer/default-layout/lib/styles/index.css';

// Create new plugin instance
const defaultLayoutPluginInstance = defaultLayoutPlugin();

// Your render function
<Viewer
    fileUrl='/path/to/document.pdf'
    plugins={[
        // Register plugins
        defaultLayoutPluginInstance,
        ...
    ]}
/>
```

// Create the plugin instance
const toolbarPluginInstance = toolbarPlugin(...);
